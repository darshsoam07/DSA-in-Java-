## 📌 About

**DSA in Java** is my personal, continuously growing repository of **Data Structures & Algorithms problems implemented in Java**.

The repository primarily contains problems from **LeetCode**, with additional problem sources and topics being added as my DSA journey progresses.

Each problem is organized independently and includes:

* ✅ A working Java solution
* 📝 A concise explanation / notes
* 🧠 The core problem-solving approach
* ⏱️ Time complexity
* 💾 Space complexity
* 🔗 Easy navigation from the main README

This repository is intended to serve as both a **learning record** and a **long-term DSA revision reference**.

```text

│   ├── 0136-single-number.java
│   └── README.md
│
├── 0151-reverse-words-in-a-string/
│   ├── 0151-reverse-words-in-a-string.java
│   └── README.md

│
```

### Folder Naming Convention

```text
<problem-number>-<problem-slug>/
```

Example:

```text

```

This makes problems:

* Easy to search
* Easy to navigate
* Consistent across the repository
* Compatible with automated tooling in the future

## 🚀 Running a Solution

Each solution is intended to be a self-contained Java program.

### 1. Clone the repository

```bash
git clone https://github.com/darshsoam07/DSA-in-Java.git
cd DSA-in-Java
```

### 2. Navigate to a problem

```bash
cd 0136-single-number
```

### 3. Compile

```bash
javac 0136-single-number.java
```

### 4. Run

```bash
java 0136-single-number
```

> Some LeetCode solutions may be written in the platform's expected class/method format rather than as standalone console programs. In those cases, use the solution directly in the corresponding coding platform or adapt the class/file name for local execution.
